# たわーばとる

なんでも積みあげる、ほのぼのタワーバトル。HTML1ファイルで動きます。

**遊ぶ**: https://tkcy3.github.io/tower-battle/

- お題を入れると、ウィキメディア・コモンズ / いらすとや / えもじ（Microsoft Fluent Emoji）の画像からパーツを自動で作ります。組み合わせもOK（自分の写真からも作れます）
- ひとり / CPU / ネット対戦（部屋ばんごうで対戦）
- ほのぼのBGMと効果音（Web Audioでその場で作っています。音源ファイルなし）
- ネット対戦はリアクションとチャットつき、再戦もできます
- 物理演算は planck.js（Box2D）、ネット対戦は PeerJS を使っています
